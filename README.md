# Смешные картинки

Сайт-галерея на GitHub Pages.

## Как добавить новую картинку
1. Открой репозиторий на GitHub → папка `images` → **Add file → Upload files** → перетащи картинку. Назови её следующим номером, например `12.png`.
2. Открой `index.html` → значок карандаша ✏️ → добавь строку в список `images`:
   `"images/12.png",`
   (запятая в конце предыдущей строки обязательна).
3. **Commit changes**. Через минуту-две изменения появятся на сайте.
